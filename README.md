# PHP Shop (ola-09)

XAMPP PHP 8 shop.

## Setup
1. Place folder in `C:\xampp\htdocs\swd\ola-09-php-shop`.
2. Create DB `swd_shop` (or import `database.sql`).
3. Run `php seed.php` from CLI to seed products.
4. Visit http://localhost/swd/ola-09-php-shop/
5. Admin: http://localhost/swd/ola-09-php-shop/admin/login.php (password: admin123)
